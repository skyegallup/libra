# Libra

Libra is a (work-in-progress) client for [the Gemini protocol](https://geminiprotocol.net) ([gemini://](gemini://geminiprotocol.net)), a lightweight web protocol that prioritizes user autonomy and privacy.

This browser intends to a modern, feature-complete Gemini client that is easy for non-techincal users to understand and browse with. More information about this project's goals and scope can be found here: [docs/goals.md](docs/goals.md).
